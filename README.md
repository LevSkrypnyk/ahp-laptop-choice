# Вибір ноутбука для розробника методом аналізу ієрархій (МАІ)

Програма до курсової роботи з дисципліни «Системний аналіз та теорія прийняття рішень».
Виконав: Скрипник Л., група КНД-31.

Програма реалізує метод аналізу ієрархій (метод Сааті) без готових пакетів типу
Expert Choice / Super Decisions: матриці парних порівнянь, вектор пріоритетів
(власний вектор), перевірка узгодженості (CI, CR), синтез глобальних пріоритетів
і простий аналіз чутливості.

## Файли

| Файл | Що робить |
|---|---|
| `ahp.py` | модуль з розрахунками МАІ (не залежить від задачі, можна використати для іншого вибору) |
| `laptop_choice.py` | моя задача: критерії, альтернативи, матриці парних порівнянь, вивід результатів і графіків |
| `results/` | результати запуску: `output.txt` (консольний вивід) і графіки `.png` |

## Задача

- **Мета:** вибір оптимального ноутбука для розробника ПЗ.
- **Критерії (7):** продуктивність, автономність, портативність, вартість, екран, надійність, дизайн.
- **Альтернативи (5):** HP Spectre x360 14, ASUS Zenbook S14, Lenovo ThinkPad X1 Carbon Gen 14,
  MacBook Pro 16 (M5 Pro), Acer Swift 14 AI.

## Запуск

```bash
pip install -r requirements.txt
python laptop_choice.py
```

Потрібен Python 3.9+. Результати виводяться в консоль, графіки зберігаються в папку `results/`.

## Як змінити під свою задачу

У `laptop_choice.py` поміняти списки `CRITERIA`, `ALTERNATIVES` і матриці
`CRITERIA_MATRIX`, `ALT_MATRICES`. Матриці задаються тільки верхнім трикутником
(оцінки можна писати як `3` або `"1/3"`), решту програма добудовує сама.
